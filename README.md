🌱 Personal Carbon Footprint Calculator
L&T Project


📌 About

A web-based application designed to calculate an individual's estimated carbon footprint based on everyday activities and lifestyle choices. It aims to promote environmental awareness and encourage sustainable living.
Prototype Link :- https://hefcacrnltx2teacg5apww.streamlit.app/

Alternate Prototype Link :- https://ecosync-carbon-calculator.streamlit.app/

✨ Features 

Calculate estimated CO₂ emissions. Track emissions from electricity and LPG usage. Estimate emissions from travel and flights. Analyse lifestyle-related carbon emissions. Display results through an interactive dashboard. Encourage eco-friendly alternatives.


🛠️ Technologies Used 

Python3 :- Core stoichiometric emission calculation engine.

Streamlit :-  Interactive sliders, dropdowns, instant web UI.​

GitHub: Version control and cloud app deployment.​

pandas :- Category breakdowns and benchmark charts.​

datetime (standard library) :-  Standard Library) Report timestamps in IST.​

Custom HTML + CSS :- Dark-green glass-card theme, score ring, KPI tiles, animated emission bars

ReportLab :- Generates the downloadable PDF report (layout, tables, vector bar chart)

io.BytesIO: Builds the PDF in memory and serves it through `st.download_button`​
